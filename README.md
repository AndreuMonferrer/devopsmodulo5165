# Módulo 5165 · Metodología DevOps: preparación de entornos de despliegue

Apuntes y actividades del módulo 5165 del curso de especialización en Despliegue de productos software en contenedores (RD 144/2026), curso 2026-2027.

Sitio publicado: https://andreumonferrer.github.io/devopsmodulo5165/

- `index.html`: portada con las 7 unidades.
- `calendario.html`: las 42 sesiones con fecha y enlace directo.
- `ra1.html` … `ra7.html`: una unidad por resultado de aprendizaje, una pestaña por sesión.
- `assets/`: estilos y script de pestañas compartidos.

Enlace directo a una sesión: `ra3.html#s14`. Para incrustar una unidad en Aules, usar un iframe con la URL de la unidad.
